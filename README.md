### 01 — AWS Data Engineering Pipeline
An end-to-end pipeline demonstrating data ingestion, transformation, orchestration, and analytics using AWS services.

- **Ingest:** raw data lands in S3 (batch and event-driven via Lambda)
- **Transform:** AWS Glue / PySpark jobs clean, validate, and partition data into a curated layer
- **Orchestrate:** Step Functions / Airflow manage scheduling, retries, and dependencies
- **Analyze:** Athena / Redshift serve analytics-ready tables for BI consumption

**Stack:** `S3` `Glue` `Lambda` `Step Functions` `Athena` `Redshift` `Python` `PySpark`
